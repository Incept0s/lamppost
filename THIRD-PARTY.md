LAMPPost itself is MIT licensed (see [LICENSE](LICENSE)). It ships one
third-party file and runs several programs that it does **not** include.

## Shipped with LAMPPost

| File | Project | License |
|------|---------|---------|
| `assets/fonts/Nunito-*.ttf` | [Nunito](https://fonts.google.com/specimen/Nunito) by Vernon Adams, Cyreal, Jacques Le Bailly | SIL Open Font License 1.1 ([OFL.txt](assets/fonts/OFL.txt)) |

The control panel is a Rust program. Its dependencies are compiled into the
binary - 342 crates in total, all under permissive licences (MIT, Apache-2.0,
BSD, Zlib, ISC, BSL-1.0, Unicode, and OFL-1.1 / Ubuntu Font Licence for the
fallback fonts egui embeds). Their complete licence notices ship with every
package as `THIRD-PARTY-LICENSES.txt`, generated by
`packaging/third-party-licenses.py`. The direct dependencies:

| Crate | What it does | License |
|-------|--------------|---------|
| [eframe / egui](https://github.com/emilk/egui) | the window and its widgets | MIT or Apache-2.0 |
| [ksni](https://github.com/iovxw/ksni) | the tray icon (StatusNotifierItem) | MIT or Apache-2.0 |
| [tokio](https://tokio.rs/) | async runtime for the tray | MIT |
| [chrono](https://github.com/chronotope/chrono) | timestamps in the log | MIT or Apache-2.0 |
| [crossbeam-channel](https://github.com/crossbeam-rs/crossbeam) | messages between threads | MIT or Apache-2.0 |
| [anyhow](https://github.com/dtolnay/anyhow) | error handling | MIT or Apache-2.0 |

## Used, not included

LAMPPost starts and configures programs that come from your distribution's
packages. They keep their own licenses and are updated by `dnf`, not by us.

| Program | Package | License |
|---------|---------|---------|
| Apache HTTP Server | `httpd`, `mod_ssl` | Apache License 2.0 |
| PHP (FPM and CLI) | `php-fpm`, `php-cli`, … | PHP License 3.01 |
| MariaDB | `mariadb-server`, `mariadb` | GPL-2.0 |
| phpMyAdmin | `phpMyAdmin` | GPL-2.0 |
| Apache Tomcat | `tomcat` | Apache License 2.0 |
| Python (runs the FTP server and the mail catcher) | `python3` | PSF |
| pyftpdlib (the FTP server) | `python3-pyftpdlib` | MIT |
| aiosmtpd (the mail catcher) | `python3-aiosmtpd` | Apache License 2.0 |
